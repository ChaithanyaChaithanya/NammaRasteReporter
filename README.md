Namma-Raste Reporter

An Android-based smart infrastructure reporting application that helps citizens quickly report public issues such as potholes, broken streetlights, and damaged roads.

Overview

Namma-Raste Reporter is designed to simplify the process of reporting civic infrastructure problems through a fast and user-friendly mobile application.

The app allows users to:

Capture images of infrastructure issues
Automatically collect GPS location and timestamp
Generate a unique Ticket ID
Store and track complaints efficiently

The project aims to improve communication between citizens and local authorities while contributing to safer roads and smarter cities.
